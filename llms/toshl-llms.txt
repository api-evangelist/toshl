# Toshl

> Toshl Finance is a personal finance and budgeting platform (500 Global portfolio) whose Toshl API at https://api.toshl.com exposes a user's complete personal-finance graph — accounts, entries (expenses and incomes), budgets, categories, tags, locations, images, currencies, exports, planning, and bank institutions/connections/imports — over a REST JSON API with OAuth 2.0 (resource:r/rw scopes) or personal-token basic auth.

Generated by API Evangelist enrichment pipeline (method: generated, 2026-07-21) from apis.yml and repo artifacts. Toshl publishes no llms.txt of its own (probed 2026-07-21).
